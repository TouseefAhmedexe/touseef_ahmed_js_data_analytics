Execution Order

See the order in which synchronous code, Promise callbacks, queueMicrotask and setTimeout run. The order is recorded while the code runs and shown on the page.

  • Analytics
  • Performance
  • Execution order

The rules

  1. The engine runs the current code to the end. This is synchronous code, and it runs on the call stack.
  2. Then it runs every microtask: Promise callbacks and queueMicrotask callbacks, in the order they were queued. Microtasks created while microtasks run are also run now.
  3. Then the browser may draw the page.
  4. Then it takes one macrotask from the task queue, such as a timer callback, and starts again at step 1.
