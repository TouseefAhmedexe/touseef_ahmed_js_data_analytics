How to read these numbers

  • Each approach runs several times, and the table shows the median. The first run is often slower, because the engine optimizes code while it runs.
  • Browsers can round the result of performance.now() to protect privacy, so a very fast operation can show as 0 or as a tiny number.
  • Other programs, a background tab and garbage collection change the numbers. Your numbers will differ from other computers, and from one run to the next.
  • The test uses simple synthetic records and only two kinds of operations, so it does not predict the speed of a real application.
  • Array.find stops at the first match, so the average work depends on where the searched ids are.
  • A Map has a cost to build. It pays off when the same data is searched many times.
  • With a small number of records, the difference is too small to matter.
